# Havenly · UK Property Intelligence

A premium UK-first property marketplace demo designed to go beyond traditional property portals.

## Highlights
- Responsive, accessible-first interface
- Buy, Rent and New Homes search modes
- Location, budget and bedroom filtering
- AI-style natural-language property search interaction
- Curated property cards with EPC and information-confidence signals
- Neighbourhood discovery
- Property intelligence / confidence layer
- Agent and buyer experience concepts
- Reduced-motion support and skip navigation
- UK-focused property terminology and trust/compliance sections

## Images
The demo uses high-resolution remote image assets for visual reference and prototyping. Replace with properly licensed production imagery before launch.

## Run locally
This is a static frontend and can be opened directly in a browser. It is also suitable for Vercel static deployment.

## Production note
This repository is a design/product demo. Before production use, connect live property, mapping, EPC, sold-price and other data sources, implement backend authentication and storage, add formal legal/privacy/cookie documents, validate accessibility with automated and manual testing, and obtain legal/compliance review for the target business model.
