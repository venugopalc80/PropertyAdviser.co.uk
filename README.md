# Havenly · UK Property Intelligence

A premium UK-first property marketplace demo designed to go beyond traditional property portals.

## Highlights
- Responsive, accessibility-first interface
- Buy, Rent and New Homes search modes
- Location, budget and bedroom filtering
- Natural-language AI-style property search interaction
- High-resolution property imagery
- Property detail views with EPC, tenure, council tax, parking and confidence signals
- Save-to-shortlist using browser storage
- Compare up to three properties
- Neighbourhood discovery
- Property intelligence / confidence layer
- Buyer and agent experience concepts
- Skip navigation and keyboard-friendly interactions
- UK-focused property terminology and trust/compliance sections

## UK product direction
The information architecture is intentionally designed around the UK's move toward clearer upfront property information. The 2026 GOV.UK reform roadmap emphasises earlier, more comprehensive property information and digitalisation, while current material-information guidance work highlights areas such as price, council tax, tenure, EPC, utilities, broadband, mobile coverage, parking, accessibility, rights/easements, flood risk, construction, defects, restrictions and planning. This demo is a product concept, not a statement of legal compliance.
