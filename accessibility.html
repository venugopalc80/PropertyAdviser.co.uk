ACCESSIBILITY

Accessibility statement

Havenly is designed as an accessible-first UK property marketplace demo. The target is WCAG 2.2 AA, with semantic structure, keyboard navigation, visible focus, meaningful labels, responsive layouts and text alternatives for images.

What the demo supports

  • Keyboard-operable navigation, controls and property cards.
  • Form labels, required fields and browser validation.
  • Responsive layouts designed for zoom and narrow screens.
  • Skip links and semantic page landmarks on updated journeys.
  • Text alternatives for property imagery where practical.

Known limitations

This demo has not received a formal third-party accessibility audit. Some visual components and third-party content may still need testing. Before production launch, representative journeys should be tested with automated tooling and manual keyboard, screen-reader, zoom, reflow and colour-contrast checks.

Feedback

A production service should provide a monitored accessibility contact method and a clear process for reporting barriers and requesting information in an accessible format.

Compliance note

This statement describes the current demo intent and does not certify compliance with WCAG or UK legal requirements.
