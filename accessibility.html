ACCESSIBILITY

Accessibility statement

Havenly is being developed with accessibility as a core requirement. The working target is WCAG 2.2 AA, using semantic HTML, keyboard-operable controls, visible focus, labels, responsive layouts, text alternatives and appropriate status messaging. WCAG conformance is not claimed until the full service has been tested.

What we are testing

  • Keyboard-only navigation and logical focus order.
  • Visible focus indicators and skip navigation.
  • Form labels, errors, required fields and status updates.
  • Responsive reflow, zoom and text scaling.
  • Colour contrast and information that is not conveyed by colour alone.
  • Meaningful alternative text for informative images.
  • Screen-reader landmarks, headings, names and accessible control states.
  • Touch target size and accessible interaction on mobile devices.

Property and account journeys

Search, property details, saving, comparison, enquiries, viewing requests, sign-in and agent workflows should all remain usable without relying solely on pointer input or visual presentation.

Known limitations

This is a development demonstration and has not received a formal independent accessibility audit. Third-party services, content, future listing data and new components can introduce barriers. Automated testing alone is not sufficient for WCAG assessment.

Feedback

Before production launch, the operator should publish a monitored accessibility contact method and a process for reporting barriers and requesting information in an accessible format.

Compliance note

This statement does not certify WCAG 2.2 AA conformance or compliance with the Equality Act 2010 or any other law. A formal audit and appropriate legal review should be completed before launch.
